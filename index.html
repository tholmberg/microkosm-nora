Microkosm Labs / Lab 003

Nora.

Nora is a local-first personal AI assistant. An experiment in building an assistant that can live close to the work, connect to tools, retain useful context, and be packaged as a repeatable system rather than a one-off demo.

Prototype lives locally
This public page documents the experiment. The assistant itself is intentionally not exposed to the public internet.
What the lab is testing

An assistant as a system.

Nora is less about making another chat window and more about the architecture around one: startup, identity, local models, external tools, memory, secure configuration, packaging, and a path another person could actually reproduce.

01 / LOCAL FIRST

Close to the work.

Designed around a local desktop experience with local model capability, deliberate external connections, and a one-click launcher.

02 / CONNECTED

Tools, not theater.

The experiment explores how an assistant can reach useful systems and data while keeping the interface coherent and the boundaries understandable.

03 / REPEATABLE

Package the learning.

The real proof is not that Nora runs once. It is whether the architecture, configuration, and documentation can turn the build into a reproducible system.
